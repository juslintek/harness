Harness design system · light

Neutral surfaces, one accent, colour only for status. Every badge shows its word.

Colour roles

--color-surface Page background
--color-surface-raised Panel, dialog, control
--color-ink Text
--color-ink-muted Secondary text
--color-border Hairline
--color-border-strong Control border
--color-brand Primary action
--color-on-brand Text on primary
--color-accent Selected surface
--color-link Link
--color-danger Danger

Status

Foreground on soft background. Always paired with the status word.

danger --status-danger --status-danger-bg
