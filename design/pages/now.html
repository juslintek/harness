Set up Acme Labs

Harness shows live work here once an organisation has a project and an agent. 1 of 6 steps is done.

✓ Create a project
A project holds the board and the repository agents work in.
Open Settings done
2 Add an agent
Agents do the work. Let Hiring interview candidates first, or add one directly if you already know the CLI and profile.
3 Set a monthly budget
Every run costs money. A budget warns at 80% and pauses the agent at 100%.
4 Invite your team
People you invite can watch agents, answer approvals and chat.
5 Add a second passkey
If you lose this device, a second passkey keeps you in.
6 Choose where you get notified
Approvals need a quick answer. Add a push, email, Slack or Telegram target.
