# harness (Zig port)

Zig 0.17.0 port of the harness server, built alongside the TS version in `../code`. Build with `zig build -Doptimize=ReleaseSafe` (binaries land in `zig-out/bin`: `harness` and `harness-hook`), test with `zig build test -Doptimize=ReleaseSafe --summary all` (add `-Dtest-filter=<name>` to narrow it), and check formatting with `zig fmt --check .` (run it before the first build: `zig-pkg/` holds the fetched httpz sources and is not formatted to our rules). `zig build check` compiles for errors only and works with `-fincremental --watch`; `zig build run -- <subcommand>` runs the server binary. SQLite 3.54.1 and libzstd 1.6.0 are vendored under `vendor/` with `SHA256SUMS`; httpz is pinned in `build.zig.zon`. Everything except the shared core files (`app`, `config`, `ids`, `json`, `errors`, `events`, `git`) is a stub for now: every subcommand prints `not implemented` and exits 2. `sgrules/` holds ast-grep rules that ban pre-0.16 std APIs (`ast-grep scan src cookbook`, rules checked against samples with `ast-grep test --skip-snapshot-tests`). Read `PORTING.md` before writing slice code: it maps each TS idiom to a Zig 0.17 pattern, and every pattern is a tested file in `cookbook/` (`zig build cookbook`).
